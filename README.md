#  Vrinda Store Data Analysis Dashboard

An end-to-end data analysis project focused on analyzing the annual sales performance of **Vrinda Store**. This project processes raw retail data to uncover critical business insights regarding customer demographics, regional demand, top sales channels, and product performance to drive data-backed business growth.

The core analysis is built upon the dataset file **Vrinda Store Data Analysis.xlsx**.

---

##  Key Insights & Business Takeaways

*   **Gender Performance:** Women are the primary drivers of revenue, accounting for over **69%** of total purchases (~21.5k orders) compared to men (~9.5k orders).
*   **Top Channels:** Platforms like **Amazon**, **Flipkart**, and **Myntra** emerge as the highest revenue-generating sales channels.
*   **Geographic Hotspots:** **Maharashtra**, **Karnataka**, and **Uttar Pradesh** stand out as the top 3 state contributors to overall sales.
*   **Product Demand:** Ethnic wear categories such as **Kurtas**, **Sets**, and **Western Dresses** dominate the order volume.

---

##  Tech Stack & Tools Used

*   **Data Source:** `Vrinda Store Data Analysis.xlsx` (Raw sales data)
*   **Data Processing:** Microsoft Excel (Data Cleaning, `IF` statements, Data Formatting)
*   **Analysis & Aggregation:** Pivot Tables
*   **Data Visualization:** Interactive Dashboard (Bar Charts, Pie Charts, Line Graphs, Slicers for dynamic filtering)

---

##  Project Structure

The project repository includes the following primary files and sheets:
*   `Vrinda Store Data Analysis.xlsx` — The main spreadsheet containing raw data and the dashboard sheets.
    *   **Vrinda Store Report / Dashboard:** The central interactive visual interface.
    *   **Vrinda Store (Raw Data):** Contains 31,000+ rows of order details (Order ID, Cust ID, Gender, Age, Channel, Category, SKU, Amount, Status, Ship-State, etc.).
    *   **Analysis Sheets:** Dedicated Pivot tables for `Sales vs Orders`, `Men vs Women`, `Order Status`, `Top states`, `Age and Gender`, and `Channels`.

---

##  Dashboard Features

The dynamic dashboard allows stakeholders to filter data instantly using interactive **Slicers**:
1.  **Month-wise Trends:** Track sales spikes and order volumes across different months to identify seasonal trends.
2.  **Demographic Breakdown:** Visualize target age groups (e.g., Adult vs Senior vs Teen) combined with gender splits.
3.  **Order Status Tracker:** Monitor the percentage of successfully Delivered orders vs Cancelled/Returned shipments.
4.  **Channel Analysis:** Compare which e-commerce platform yields the highest profitability.
